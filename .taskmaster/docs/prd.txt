# Mock API 마이그레이션 프로젝트 PRD (Product Requirements Document)

## 프로젝트 개요

### 프로젝트 명
콜로소 DevBrother2 Mock API → Express API 마이그레이션

### 프로젝트 목표
현재 `mock.json`을 사용하는 클라이언트 API를 실제 Express 백엔드 API로 단계적으로 마이그레이션하여 프로덕션 환경에서 사용할 수 있는 완전한 API 시스템을 구축한다.

### 비즈니스 가치
- 실제 사용자 데이터 처리 가능
- 확장 가능한 백엔드 아키텍처 구축
- 실시간 데이터 동기화 지원
- 보안 및 성능 최적화

## 현재 상태 분석

### 기존 시스템
- **프론트엔드**: Next.js 14 + React 18 + TypeScript
- **상태관리**: Valtio (클라이언트) + TanStack Query (서버)
- **API 통신**: `mock.json` 기반 정적 데이터
- **HTTP 클라이언트**: `client/http.ts` 추상화 계층

### 마이그레이션 대상 API 모듈
1. **auth**: 인증 및 로그인 관리
2. **user**: 사용자 정보 관리
3. **order**: 주문 관리
4. **product**: 상품 관리
5. **course**: 강의 관리
6. **enrollment**: 수강 신청 관리
7. **voucher**: 쿠폰 관리
8. **display**: 콘텐츠 전시
9. **search**: 검색 기능
10. **exchange**: 환율 관리

## 기능 요구사항

### 1단계: 핵심 인증 시스템 (P0)

#### Auth API 마이그레이션
- **로그인 API**: POST /api/auth/signin
  - 이메일/비밀번호 인증
  - JWT 토큰 발급 (accessToken, refreshToken)
  - 로그인 실패 시 적절한 에러 메시지
- **회원가입 API**: POST /api/auth/signup
  - 이메일 중복 확인
  - 비밀번호 암호화
  - 이메일 인증 플로우
- **로그아웃 API**: POST /api/auth/signout
  - 토큰 무효화
  - 서버 측 세션 정리
- **토큰 갱신 API**: POST /api/auth/refresh
  - refreshToken 검증
  - 새로운 accessToken 발급

#### User API 마이그레이션
- **사용자 정보 조회**: GET /api/users/me
  - 인증된 사용자 정보 반환
- **사용자 정보 수정**: PUT /api/users/me
  - 프로필 정보 업데이트
- **사용자 강의 목록**: GET /api/users/courses
  - 구매한 강의 목록 조회
- **사용자 쿠폰 목록**: GET /api/users/vouchers
  - 보유 쿠폰 목록 조회

### 2단계: 상거래 시스템 (P1)

#### Order API 마이그레이션
- **주문 생성**: POST /api/orders
  - 상품 주문 생성
  - 결제 정보 검증
  - 재고 확인
- **주문 목록 조회**: GET /api/orders
  - 사용자별 주문 내역
  - 페이지네이션 지원
- **주문 상세 조회**: GET /api/orders/:id
  - 주문 상세 정보
  - 결제 상태 확인

#### Product & Course API 마이그레이션
- **상품 목록 조회**: GET /api/products
  - 카테고리별 필터링
  - 검색 기능
- **상품 상세 조회**: GET /api/products/:id
  - 상품 상세 정보
  - 관련 강의 정보
- **강의 상세 조회**: GET /api/courses/:id
  - 강의 챕터 정보
  - 미리보기 콘텐츠

### 3단계: 학습 관리 시스템 (P2)

#### Enrollment API 마이그레이션
- **수강 신청**: POST /api/enrollments
  - 강의 수강 신청
  - 중복 신청 방지
- **수강 목록 조회**: GET /api/enrollments
  - 수강 중인 강의 목록
  - 진행률 정보

#### Voucher API 마이그레이션
- **쿠폰 조회**: GET /api/vouchers
  - 사용 가능한 쿠폰 목록
- **쿠폰 적용**: POST /api/vouchers/apply
  - 주문에 쿠폰 적용
  - 할인 계산
- **쿠폰 다운로드**: POST /api/vouchers/download
  - 프로모션 쿠폰 다운로드

### 4단계: 콘텐츠 관리 시스템 (P3-P4)

#### Display, Search, Exchange API 마이그레이션
- **콘텐츠 전시**: GET /api/displays
  - 메인 페이지 콘텐츠
  - 큐레이션 데이터
- **검색 기능**: GET /api/search
  - 통합 검색
  - 자동완성 지원
- **환율 정보**: GET /api/exchange
  - 실시간 환율 데이터

## 기술 요구사항

### 백엔드 기술 스택
- **런타임**: Node.js 18+
- **프레임워크**: Express.js
- **데이터베이스**: PostgreSQL 또는 MongoDB
- **인증**: JWT (JSON Web Token)
- **보안**: bcrypt, helmet, cors
- **검증**: joi 또는 zod
- **로깅**: winston
- **테스트**: Jest

### 인프라 요구사항
- **환경 변수 관리**: dotenv
- **API 문서화**: Swagger/OpenAPI
- **데이터베이스 마이그레이션**: Knex.js 또는 TypeORM
- **캐싱**: Redis (선택사항)
- **모니터링**: 로그 시스템 구축

### 보안 요구사항
- **HTTPS 적용**: SSL/TLS 인증서
- **CORS 설정**: 허용된 도메인만 접근
- **Rate Limiting**: API 호출 제한
- **입력 검증**: 모든 API 입력 데이터 검증
- **SQL Injection 방지**: 파라미터화된 쿼리 사용
